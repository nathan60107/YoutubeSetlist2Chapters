**YouTube Setlist to Chapters** は、コメント欄に投稿されたセットリストを YouTube のプログレスバー上のチャプターに変えるツールです。

歌枠・ライブにはチャプターがほとんど付いていませんが、コメント欄にはたいてい曲名と開始時刻を書き出してくれた人がいます。このスクリプトはそのコメントを見つけてプログレスバーに描き込むので、どの曲がどこにあるのかが一目で分かり、聴きたい曲へそのまま飛べます。

## 機能

- **設定不要** — 動画を開けばチャプターが勝手に現れます。アカウントも API キーも料金も不要
- **コメントからセットリストを自動で探す** — コメント欄を調べて最もセットリストらしいものを選ぶので、投稿者がチャプターを付けていない動画でも使えます
- **公式チャプターを尊重** — 投稿者自身がチャプターを付けた動画では何もせず、進行バーを一番よく分かっている人に譲ります
- **さまざまな書式に対応** — よくあるタイムスタンプ形式（`0:00`、`00:00`、`0:00:00`）、`4:55~7:52` のような区間表記、`01.`・`①`・`１` などの番号、行内のどこに置かれたタイムスタンプ、曲名がタイムスタンプの次の行に書かれたレイアウト
- **カーソルを乗せれば曲名** — プログレスバー上の区間にカーソルを合わせると、その曲名が表示されます

## インストール

手順は 2 つ。まずユーザースクリプトマネージャーを入れ、次にこのスクリプトを入れます。すべて無料で、1 分ほどで終わります。

### 手順 1：ユーザースクリプトマネージャーを入れる

[Tampermonkey](https://www.tampermonkey.net/) のサイトを開き、使っているブラウザを選んで「Chrome に追加」（または相当するボタン）を押します。インストールが終わると、ブラウザの右上に新しいアイコンが追加されます。

すでに別のユーザースクリプトマネージャーを使っている場合は、そのままで構いません。

### 手順 2：このスクリプトを入れる

[Greasy Fork のスクリプトページ](https://greasyfork.org/ja/scripts/589468-youtube-setlist-to-chapters)を開き、緑色の「このスクリプトをインストール」ボタンを押します。ユーザースクリプトマネージャーの確認画面が開くので、そこでもう一度「インストール」を押せば完了です。

この repo の `dist/` にある `.user.js` を直接インストールすることもできます。

### 使い方

1. YouTube で歌枠・ライブを開きます
2. 少し待つと、コメントが読み込まれてプログレスバーに 1 曲ずつ色付きの区間が現れます
3. 区間にカーソルを合わせると曲名が表示され、クリックするとその曲へ飛びます
4. 何も出ない場合は、その動画のコメントにセットリストと判定できるものが無かったということです

## ロードマップ

予定している機能と改善：

- **説明欄の解析** — コメントだけでなく動画の説明欄からもセットリストを検出
- **手動選択** — 自動判定が外れたとき、使うコメントを自分で指定できるようにする
- **設定パネル** — 上記のオプションを切り替えられるようにする
- **結果のキャッシュ** — 動画ごとに選んだセットリストを記憶し再解析を回避
- **多言語UI** — インターフェースの多言語化
- **ブラウザ拡張機能** — ユーザースクリプトに加えて、パッケージ化した拡張機能を提供

## 開発

```bash
# 依存関係のインストール
npm install

# ライブリロードつき開発モード
npm run dev

# 本番ビルド（全プラットフォーム）
npm run build-prod
```
